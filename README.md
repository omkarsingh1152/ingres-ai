# 🌍 INGRES-AI

> **AI-Powered Groundwater Intelligence Platform**
>
> Helping users explore groundwater resources, analyze data, visualize maps, and run AI-powered simulations for better water resource management.

---

## 📖 About

INGRES-AI is an intelligent groundwater management platform built for hackathons and real-world applications.

The platform enables users to:

- 🔍 Ask groundwater-related questions using AI
- 🗺️ Explore groundwater information on an interactive map
- 📊 Visualize groundwater statistics
- 🤖 Run AI-powered simulations
- 👨‍💼 Access an administration dashboard
- ⭐ Save important locations and queries

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/omkarsingh1152/INGRES-AI.git
```

```
cd INGRES-AI
```

---

## Backend

```
cd backend
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run backend

```bash
uvicorn main:app --reload
```

---

## Frontend

```
cd frontend
```

Install packages

```bash
npm install
```

Run

```bash
npm run dev
```

---

# 🌐 Environment Variables

Create a `.env` file.

Example:

```env
GEMINI_API_KEY=your_api_key
MONGO_URI=your_mongodb_uri
```
